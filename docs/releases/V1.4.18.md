## Affiliation Amazon

- Les imports CSV, ZIP et portail consultent le même historique des relevés. Une
  référence CSV manuelle se corrige par un autre import CSV confirmé.
- Les corrections partielles préservent les valeurs déjà validées. Une archive
  contenant une vue financière non interprétable reste à vérifier avant de modifier
  les totaux existants.
- Les articles retournés sont disponibles dans les statistiques lorsque le
  rapport les fournit. Les rapports conservent leur provenance et leur empreinte.

## Disponibilité et statistiques

- LinKs libère SQLite avant d’attendre le navigateur de collecte. La lecture de
  la configuration publique et la résolution des redirections restent disponibles
  pendant une écriture SQLite en mode WAL.
- Les statistiques distinguent le placement déclaré du référent observé. Les
  préchargements signalés et les robots détectés sont exclus des ouvertures.

## Mise à jour

- LinKs crée la table `redirect_observations` au démarrage. Les URLs, destinations
  et compteurs historiques sont conservés. Les référents disponibles concernent
  les futures ouvertures.
- Les exports JSON antérieurs restent restaurables. Une sauvegarde qui contient
  des relevés avec retours exige V1.4.18 ou une version compatible.
