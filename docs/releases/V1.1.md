## Mise à jour d’une instance existante

Avant de remplacer l’image, exécuter `scripts/preserve-instance.py` dans l’ancienne image pour transférer les assets et la configuration historique vers `/data`, puis inclure ces fichiers dans la sauvegarde externe. Voir `docs/INSTALL.md`.

Conserver le compose, le volume persistant et la protection externe actuels. Une instance historique reste en `auth.mode = external` ; aucun compte local ne lui est imposé.

Images : `ghcr.io/mick7784/links:v1.1` et `ghcr.io/mick7784/links:latest` (AMD64/ARM64).

La publication de l’image ne redémarre pas automatiquement l’instance de production.
